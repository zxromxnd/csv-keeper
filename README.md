# CSV Keeper

Українська | [English](README.en.md)

Безкоштовний конвертер CSV і TSV у Excel. Зберігає початкові нулі, довгі ідентифікатори та текст без автоматичного перетворення на числа чи дати.

[Відкрити сайт](https://csv-keeper.netlify.app/) · [Тестовий CSV](public/examples/check.csv)

## Як користуватися

1. Виберіть або перетягніть CSV/TSV чи відкрийте вбудований приклад.
2. Перевірте таблицю. За потреби змініть роздільник, кодування та наявність заголовка.
3. Залиште коди й ідентифікатори текстом. Для кількості та інших чисел виберіть числовий тип стовпця.
4. Завантажте XLSX та відкрийте його в Excel або LibreOffice Calc.

Працює у сучасному браузері на Windows, Linux і macOS. Встановлювати програму для конвертації не потрібно. Інтерфейс українською та англійською.

## Тестовий файл

Завантажте [check.csv](public/examples/check.csv). Виберіть UTF-8, кому та перший рядок як заголовок. Залиште всі стовпці текстовими, крім `Quantity`, який можна перетворити на число.

Перевірте результат:

- `001234` і `000007` зберігають нулі.
- `12345678901234567890` зберігає всі цифри.
- `Кава`, `Чай, зелений` та `Він сказав "привіт"` відображаються без змін.
- `=1+1` залишається текстом, а не результатом обчислення.
- Порожня комірка лишається порожньою. Перенос рядка у примітці зберігається; для перегляду увімкніть перенесення тексту в табличному редакторі.

## Обмеження

- До 5 МіБ, 10 000 рядків із заголовком, 100 стовпців і 100 000 комірок.
- До 32 767 одиниць UTF-16 у комірці.
- Кодування: UTF-8, Windows-1251, UTF-16LE. Роздільники: кома, крапка з комою, табуляція та `|`.
- Рядки мають містити однакову кількість полів. Пошкоджені лапки та нерівні рядки відхиляються.
- Числовий режим приймає десяткові числа з крапкою, до 15 значущих цифр. Значення з початковими нулями, експонентою або неоднозначним форматуванням потрібно залишати текстом.
- Дати зберігаються текстом. XLS/XLSX не приймаються на вхід. Уже втрачені в початковому файлі цифри відновити неможливо.

## Обробка даних

Файл обробляється в пам'яті браузера. Його вміст не надсилається на сервер і не зберігається в локальному сховищі. Немає реєстрації, реклами чи аналітики. Хостинг отримує звичайні запити на завантаження сторінки.

Рядки, схожі на формули, записуються в XLSX як текст. Значення CSV не виконуються як HTML. Очищення завершує обробку та прибирає завантажену таблицю.

## Розробка

Потрібні Git і Node.js 22 або новіший. Команди для Linux, macOS і Windows:

```sh
git clone https://github.com/zxromxnd/csv-keeper.git
cd csv-keeper
npm ci
npm run dev
```

Відкрийте адресу Vite. Якщо PowerShell блокує `npm.ps1`, використовуйте `npm.cmd` замість `npm`.

```sh
npm test
npm run build
npx playwright install chromium
npm run test:e2e
```

На Linux для браузерних тестів можуть знадобитися системні залежності: `npx playwright install --with-deps chromium`. Для тестів у встановленому Edge на Windows задайте `$env:PLAYWRIGHT_CHANNEL="msedge"`.

| Файл | Призначення |
| --- | --- |
| `index.html` | HTML-сторінка та точка входу |
| `src/main.ts` | Інтерфейс, переклади, події та стан |
| `src/style.css` | Оформлення й адаптивна верстка |
| `src/core.ts` | Розбір CSV, перевірки та типи комірок |
| `src/worker.ts` | Обробка поза основним потоком |
| `src/xlsx.ts` | Створення XLSX |
| `tests/` | Перевірки даних і браузерних сценаріїв |

TypeScript, Vite, Papa Parse, write-excel-file та fflate. Сервер застосунку й база даних не потрібні.

`npm run build` створює `dist` для статичного хостингу. На Netlify завантажте її вміст, включно з `_headers`. Архів вихідного коду створюється під час збірки.
