# Runtime dependencies

The application bundles the following libraries, without modifications:

- Papa Parse 5.7.0 — MIT, Matthew Holt and contributors. https://github.com/mholt/PapaParse
- write-excel-file 4.1.1 — MIT, Nikolay Kuchumov / catamphetamine. https://gitlab.com/catamphetamine/write-excel-file
- fflate — MIT, Arjun Barrett. https://github.com/101arrowz/fflate

Full runtime license texts are copied into `public/third-party-licenses.txt`, included in the built site. Exact installed versions are recorded in package-lock.json. Development dependencies are not part of the deployed runtime bundle.
